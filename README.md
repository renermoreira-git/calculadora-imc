# 🧮 Calculadora de IMC

Uma calculadora de IMC (Índice de Massa Corporal) desenvolvida em **Python** utilizando a biblioteca **Tkinter** para criação da interface gráfica.

## 📌 Sobre o projeto

O projeto permite que o usuário informe seu **peso** e sua **altura** e, a partir desses dados, calcula o Índice de Massa Corporal (IMC).

Após o cálculo, o programa apresenta o valor do IMC e sua respectiva classificação.

## 🚀 Funcionalidades

- Informar o peso em quilogramas (kg)
- Informar a altura em metros (m)
- Calcular o IMC automaticamente
- Exibir o valor do IMC
- Classificar o resultado em:
  - Abaixo do peso
  - Peso normal
  - Sobrepeso
  - Obesidade

## 🛠️ Tecnologias utilizadas

- **Python**
- **Tkinter**
